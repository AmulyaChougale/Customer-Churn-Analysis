##  Bank Customer Churn Analysis


The project analyzes customer churn behavior using a dataset of 10,000 bank customers. The objective is to identify patterns and factors that contribute to customer attrition and provide insights that can help improve customer retention.

The workflow includes data preprocessing, exploratory data analysis (EDA) using Python, and interactive dashboard creation using Power BI. Various customer attributes such as demographics, financial information, product usage, and engagement levels were analyzed to understand their relationship with churn.

Key insights highlight how factors like customer activity status, number of bank products, geographic location, and age groups influence churn patterns.The project demonstrates a complete data analytics pipeline including data cleaning, exploratory analysis, visualization, and business insight generation.

###  Tools Used:

Python (Pandas, Matplotlib, Seaborn)

Power BI
