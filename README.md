# Customer Churn Analysis & Prediction

An end-to-end Customer Churn Analysis project combining Machine Learning and Power BI to analyze customer behavior, predict churn risk, and generate business insights for retention strategies.

---

## Project Overview

The project includes:
- Data preprocessing and analysis using Python
- Customer churn prediction using Machine Learning
- Model saving and reusable prediction pipeline
- Interactive Power BI dashboard for churn analysis and KPI tracking

---

## Tech Stack

### Python & ML
- Python
- Pandas
- Scikit-learn
- XGBoost
- SMOTE
- Joblib

### Dashboard & Visualization
- Power BI
- Power Query
- DAX

---

## Machine Learning Workflow

- Performed data preprocessing and feature engineering
- Handled class imbalance using SMOTE
- Trained XGBoost churn prediction model
- Evaluated model using:
  - Precision
  - Recall
  - F1-score
  - ROC-AUC
- Saved trained pipeline using `joblib`
- Built prediction system for churn probability analysis

---

### KPI Metrics

### Churn Analysis
- Churn by Geography
- Churn by Gender
